# 3. Reglas de negocio

| ID | Regla |
|---|---|
| RN-01 | Un pedido solo puede cancelarse mientras esté en estado **pendiente**. |
| RN-02 | Un domiciliario solo puede acceder a la información de los pedidos que le han sido asignados. |
| RN-03 | Un producto marcado como **no disponible** no puede agregarse a un nuevo pedido. |
| RN-04 | El precio de un producto no puede ser negativo ni igual a cero. |
| RN-05 | Un cliente debe tener una cuenta registrada y una sesión iniciada para realizar un pedido. |
| RN-06 | Eliminar un producto del menú no debe afectar pedidos históricos que ya lo contienen. |
