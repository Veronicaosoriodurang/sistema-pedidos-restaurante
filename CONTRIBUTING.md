# Contribución

Este repositorio corresponde a un proyecto académico.

## Flujo recomendado

1. Crear una rama por funcionalidad o documento.
2. Utilizar nombres descriptivos, por ejemplo:
   - `docs/requisitos`
   - `feature/gestion-pedidos`
   - `feature/gestion-menu`
3. Realizar commits pequeños y claros.
4. Revisar que los cambios mantengan trazabilidad con los requisitos del sistema.
5. Integrar cambios a la rama principal únicamente cuando estén revisados.

## Convención sugerida de commits

- `docs:` documentación
- `feat:` nueva funcionalidad
- `fix:` corrección
- `refactor:` reorganización de código
- `test:` pruebas
- `chore:` tareas de mantenimiento
